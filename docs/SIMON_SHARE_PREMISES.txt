[A] 당장 시급 정리문서 (공유 전제)
목표 한 줄: 외부 판매 없음, 브로커는 KIS 단일, 기존 채팅·대시보드 UI 재사용, Qwen2.5-14B는 격리·게이트 뒤, Simon은 오케스트레이터(팩트 조립·울타리·로그만 신뢰).

지금 반드시 고정할 것
- SSOT: 로컬 main 실트리 하나만 진실. 임시 산출물 난립 금지.
- 브로커 팩트: NormalizedQuote / Balance 등 정규화 스키마만 UI·TTS·LLM 입력에 사용. LLM이 숫자·팩트 수정 불가.
- 주문: 기본은 조회·잠금. "주문 모드 시작" 같은 명시 전에는 주문 함수 경로 비활성.
- 200 OK: 접수일 뿐, 체결 아님. UI·TTS는 체결 매칭 전 [접수 완료·체결 대기] 고정 톤.
- 레이트: 모의 2 rps / 토큰 1 rps / WS 41 구독 상한 전제. 즉답 = 캐시+스로틀, 주문 직전만 bypass 단일 슬롯.
- 전산 단절: LLM 호출 차단 + 고정 경고 템플릿만.
- 로그: 토큰 원문 금지. qwen_raw는 마스킹 + rolling + 용량 상한.

당장 하지 말 것
- 실전 키로 장중 실험, broker_submit 기본 ON, 프로필 스위치는 체크리스트+계약 테스트 전 금지.

클라우드 vs 로컬
- 클라우드 repo는 P0 스캐폴드일 수 있음. 실구현·UI·운영 검증의 기준은 로컬 실트리.
