--------------------------------------------------------------------
0. 브로커 이관 (키움 제거)
--------------------------------------------------------------------
- 키움 OpenAPI / ActiveX / 32비트 브리지 전면 제거 대상에 다음을 포함한다.
  [필수] 실시간 등록·수신 경로 (SetRealReg·실시간 콜백·OnReceiveRealData 등 RTC 전부).
  [필수] KiwoomAPI·IPC 키움 전용 명령·가격 TR 전용 분기·키움 로그인/재접속 루프.
  [필수] HTS 연동 전제 코드, 키움 전용 설정 키·문서 링크.
- dead code 잔류 금지: 분기만 막아두지 말고, 빌드·import 경로에서 제거해 혼선을 없앤다.
- 대체: KIS REST + WebSocket, 정규화 스키마(NormalizedQuote 등), TokenManager 단일 경로.

--------------------------------------------------------------------
1. 서버 자동 연결 런처 (이 저장소 기준)
--------------------------------------------------------------------
- 기본: scripts/start_simon_all.bat → 프로젝트 루트에서 py/python3 로
  `python -m ops.launcher start --target server`
  동작: 기존 PID(런처 상태·pid 파일) 정리 → server.py 기동 → /api/status 준비까지 대기 → 대시보드 탭 오픈.
- 이미 서버가 떠 있을 때 재기동 없이 확인만: 
  `python -m ops.launcher ensure --open-browser`
  (미기동이면 start와 동일하게 기동한다.)
- 로그: runtime/simon_ops.log , PID: runtime/simon_ops.pid
- 포트: STOCK_SERVER_PORT (기본 8080)
