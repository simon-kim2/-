로컬 PC (예: c:\주식ai\stock_trading) 동기화 — 반드시 읽을 것
--------------------------------------------------------------------
- 이 문서와 ops.launcher 등은 "클라우드/원격 저장소" 브랜치
  (예: cursor/resident-chat-sse-6d82, PR #4)에 반영된 뒤,
  로컬에서 pull/merge 하기 전까지는 로컬 트리에 없을 수 있다. 없음 = 동기화 안 된 상태.
- 로컬에 git 이 있으면 (저장소 루트에서):
    git fetch origin cursor/resident-chat-sse-6d82
    git checkout cursor/resident-chat-sse-6d82
  또는 작업 브랜치에 병합:
    git fetch origin
    git merge origin/cursor/resident-chat-sse-6d82
- git 이 없으면: GitHub에서 해당 브랜치 ZIP 받거나 PR Merge 후 원격에서 pull.
- 반영 후 존재 확인할 파일(최소):
    docs/SIMON_WORK_DIRECTIVE.txt
    docs/SIMON_SHARE_PREMISES.txt
    ops/launcher.py
    ops/__init__.py
    scripts/start_simon_server_ensure.bat
    simon_ops/kis_token_manager.py
- start_simon_all.bat: 로컬이 "api/health + check_simon_status.ps1" 등으로 커스텀되어 있으면
  자동으로 덮어쓰지 말 것. 선택지 (1) 수동으로 ops.launcher 한 줄만 이식
  (2) 이 저장소용으로 scripts/start_simon_ops_p0.bat 를 별도 두고 기존 배치는 유지.
- 이 P0 서버의 준비 확인 URL은 /api/status 이다 (/api/health 아님).

--------------------------------------------------------------------
0. 브로커 이관 (키움 제거)
--------------------------------------------------------------------
- 키움 OpenAPI / ActiveX / 32비트 브리지 전면 제거 대상에 다음을 포함한다.
  [필수] 실시간 등록·수신 경로 (SetRealReg·실시간 콜백·OnReceiveRealData 등 RTC 전부).
  [필수] KiwoomAPI·IPC 키움 전용 명령·가격 TR 전용 분기·키움 로그인/재접속 루프.
  [필수] HTS 연동 전제 코드, 키움 전용 설정 키·문서 링크.
- dead code 잔류 금지: 분기만 막아두지 말고, 빌드·import 경로에서 제거해 혼선을 없앤다.
- 대체: KIS REST + WebSocket, 정규화 스키마(NormalizedQuote 등), TokenManager 단일 경로.

--------------------------------------------------------------------
1. 서버 자동 연결 런처 (이 저장소 기준)
--------------------------------------------------------------------
- 기본: scripts/start_simon_all.bat → 프로젝트 루트에서 py/python3 로
  `python -m ops.launcher start --target server`
  동작: 기존 PID(런처 상태·pid 파일) 정리 → server.py 기동 → /api/status 준비까지 대기 → 대시보드 탭 오픈.
- 이미 서버가 떠 있을 때 재기동 없이 확인만: 
  `python -m ops.launcher ensure --open-browser`
  (미기동이면 start와 동일하게 기동한다.)
- 로그: runtime/simon_ops.log , PID: runtime/simon_ops.pid
- 포트: STOCK_SERVER_PORT (기본 8080)
