SIMON 리스크 레지스터 — 추가 보강 (기존 오케스트레이터·감옥·라우팅 논의와 별도 축)
목적: 개발·운영 검토 시 체크리스트. 법률·세무는 전문가 자문 영역.

================================================================================
1) 브로커·주문

• 주문 응답 ≠ 체결
  접수·정정·거부·부분체결·미체결이 섞이면 UI가 "완료"처럼 보일 수 있음.
  힌트: 상태 머신을 주문 단위로 표시; "접수만"과 "체결 확정"을 필드·문구·색상으로 분리.

• 멱등성
  재시도·중복 클릭·음성 반복 시 이중 주문.
  힌트: 브로커 규격에 맞는 멱등/클라이언트 키 + 로컬 디바운스 + 제출 단일 슬롯.

• 장 운영 이벤트
  상한가·거래정지·정리매매·분할·상장폐지 등으로 가격·수량 로직이 조용히 깨짐.
  힌트: 종목별 거래가능·시장 경고 플래그를 스냅샷에 넣고, 미지원 구간은 "거래 불가/데이터 제한"으로 명시.

================================================================================
2) 실시간·데이터

• WS 재접속·갭
  끊김 후 빈 구간이 있어도 마지막 값이 "실시간"처럼 보일 위험.
  힌트: 마지막 틱 시각·신뢰도 라벨; 갭 감지 시 "비실시간" 배너 + REST 리콘실(명세와 동일 축).

• 시계·타임존
  체결시각·장 전후 판단 오류 시 전략·로그 전반이 어긋남.
  힌트: 저장은 UTC·표시는 명시 TZ; 브로커 필드 매핑 테이블에 시각 필드 단위 고정.

• 캐시 일관성
  TTL 캐시가 주문 직전 판단과 섞이면 옛 가격으로 판단 위험.
  힌트: 주문 경로만 cache-bypass 또는 "주문용 스냅샷" 별도 fetch; 조회용 캐시와 키 분리.

================================================================================
3) 보안·운영

• 로컬 PC 단일 실패 지점
  난독화·백업·복구 없으면 키 유출·랜섬 등에 취약.
  힌트: 시크릿 최소 보관·OS 디스크 암호화·오프라인 백업; 키는 재발급 가능 구조.

• 의존성 공급망
  pip 패키지·업데이트가 조용히 행동 변경.
  힌트: lock 파일·주기적 고정 버전 빌드; 장중엔 업데이트 금지 정책.

• 자동 업데이트·백신
  장중 프로세스 kill 가능.
  힌트: 거래 시간대 집중 모드·예외 등록 또는 세션 전 업데이트 창 고정.

================================================================================
4) 음성·UX

• 확인 음성 오인식
  "아니"를 "응"으로 듣는 순간이 가장 위험한 사고 클래스.
  힌트: 부정·긍정 화이트리스트·2단계 확인·화면 확정과 음성 동등 권한(명서 축).

• TTS vs 화면 문구 불일치
  사용자가 잘못된 확신.
  힌트: speak_text는 단일 스키마에서만 생성; TTS 전용 문자열과 UI 문자열 소스 통일.

================================================================================
5) 법·책임 (개인용이라도)

• 자동화·알고리즘 매매 표기·세무·기록
  개인용이어도 장후 정리·증빙 리스크는 남을 수 있음.
  메모: 구체 법률·세무 자문은 전문가 영역; 시스템은 주문·체결 로그 보존 정책을 명시할 뿐.

================================================================================
6) 인간·프로세스

• 설정 드리프트
  .env·모의/실전 스위치가 하나만 틀리면 재현 불가한 유령 버그.
  힌트: /api/status에 broker_profile·프로파일 해시·git_hash 노출; 부팅 시 한 번 검증.

• 문서/코드 불일치
  SSOT 브랜치·기준 커밋이 깨지면 비용 재폭증.
  힌트: "이 커밋에서만 재현" 규칙; PR·로컬 동기화 루틴.

================================================================================
