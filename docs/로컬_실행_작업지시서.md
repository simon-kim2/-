# Simon 로컬 실행 작업지시서 (Windows)

대상 폴더: `C:\주식ai\stock_trading`  
브라우저 주소: `http://127.0.0.1:18080`

이 문서만 위에서부터 순서대로 따라 하면 됩니다.  
**웹 마이크 버튼 없이 “사이먼”으로 말하려면 Resident가 켜져 있어야 합니다.**

---

## 준비 (최초 1회)

### 1. Whisper용 Python 경로 정하기

- **64비트** Python (Whisper 설치된 것)
- Kiwoom용 **32비트** Python과 **다를 수 있음**

경로 확인 예:

```bat
where python
```

Whisper 설치 확인:

```bat
"C:\여기에\64bit-python.exe" -c "import whisper; print('ok')"
```

### 2. 환경 파일 수정

1. `config\local_simon.env.example` 를 복사해서  
   `config\local_simon.env` 로 저장
2. 메모장으로 열어 **`SIMON_RESIDENT_PYTHON=`** 에 64bit python 전체 경로 입력  
   예: `SIMON_RESIDENT_PYTHON=C:\Users\you\AppData\Local\Programs\Python\Python312\python.exe`
3. 마이크가 안 되면 `SIMON_STT_DEVICE_INDEX=0` 으로 바꿔 보기 (기본 1)

## `Resident 시작 실패: resident_pid_not_alive_after_timeout` 일 때

**의미:** 20초 안에 Resident 프로세스가 살아 있지 않음 (안 뜨거나 바로 죽음).

### A. 에러 문구 직접 보기 (가장 중요)

`scripts\04_Resident_직접실행_에러보기.bat` 더블클릭  
→ 검은 창에 **빨간 글씨/Traceback** 이 나오면 그게 원인.

| 자주 나오는 메시지 | 해결 |
|--------------------|------|
| `No module named whisper` | 64bit python에 `pip install openai-whisper sounddevice` |
| 마이크 / device | `config\local_simon.env` 에서 `SIMON_STT_DEVICE_INDEX=0` |
| 파일 없음 | `tools\simon_resident_agent.py` 있는지 확인 |
| 20초 넘게 로딩만 함 | bat 직접 실행 후 1분 기다려 pid 생기는지 확인 |

### B. 로그 위치

| 파일 | 용도 |
|------|------|
| `data\logs\resident\resident_spawn.log` | 서버/bat가 Resident 띄운 기록 |
| `data\logs\resident\resident_agent.log` | Resident python 로그 (있으면) |
| `data\logs\resident\resident_agent.pid` | 살아 있는 PID |
| `data\logs\chat_v2_messages.jsonl` | 채팅 기록 (Resident 실패 원인 아님) |
| `data\logs\ipc_events.jsonl` | 자동매매/긴급정지 IPC (Resident와 무관) |

### C. 헬스 체크 (CMD)

```bat
cd /d C:\주식ai\stock_trading
call scripts\00_로컬_환경설정.bat
"%SIMON_RESIDENT_PYTHON%" tools\resident_health_check.py
```

`FAIL_REASONS` 를 읽으면 됩니다.

## 18080 포트 / Access denied

1. 작업 관리자 → **python** 여러 개면 Simon 관련만 남기고 종료  
2. 관리자 CMD:

```bat
netstat -ano | findstr :18080
```

3. `scripts\01_서버_시작.bat` 다시 실행 (창 **하나만**)

---

## 버튼 의미 (chat_v2)

| 버튼 | 설명 |
|------|------|
| 예수금 / 현황 / 전략 | 상태만 조회 (`/api/status`) |
| 자동매매 ON | 조건 안 맞으면 **409 거절** (정상) |
| 음성대화 ON | **TTS만**, Resident 안 켬 |
| Resident 시작 | 마이크 상주 프로세스 시작 |
| 긴급중지 | 거래 HOLD·주문 차단 IPC |
